# Lilim Desktop App

This repository hosts the official installers for the **Lilim Desktop App**.

Lilim is a Windows application that uses your webcam to track screen time and remind you to take regular eye rests. It features automatic eye-detection calibration and syncs with the Lilim web dashboard to track your progress, badges, and leaderboard stats.

## 📥 How to Download and Install

1. Go to the [**Releases**](https://github.com/nicolemargaret23/lilim-download/releases/latest) page.
2. Download the latest `Lilim.zip` file.
3. Extract the folder anywhere on your computer.
4. Double-click `Lilim.exe` to launch the app.

> **Note for Windows Users:** Because this application is not code-signed, Windows SmartScreen might show a warning on first launch. Click **"More info"** and then **"Run anyway"** to proceed.
